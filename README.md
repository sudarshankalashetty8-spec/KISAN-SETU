# KISAN-SETU
# 🌾 Kishan Setu – Farmer Procurement Management System
**A Smart Digital Platform for Farmers and Agricultural Procurement**

## 📌 About the Project
Kishan Setu is a web-based Farmer Procurement Management System developed to simplify and improve the agricultural procurement process. The platform helps farmers register, book procurement slots, monitor queue status, track payments, and communicate with administrators.

The main aim of this project is to reduce farmers' waiting time, improve transparency, and make agricultural procurement easier through digital technology.

## 🎯 Problem Statement
Farmers often face several challenges during agricultural procurement, such as:
- Long waiting times at procurement centres.
- Lack of information about procurement schedules.
- Difficulty tracking procurement and payment status.
- Poor communication between farmers and administrators.
- Uncertainty regarding queue management.
Kishan Setu provides a digital solution to overcome these challenges.

## ✨ Key Features
- 👨‍🌾 **Farmer Registration & Login** – Secure farmer account access.
- 📅 **Slot Booking** – Book convenient procurement slots.
- 🔄 **Real-Time Queue Management** – Monitor queue information.
- 🔔 **Notifications** – Receive important procurement updates.
- 💰 **Payment Tracker** – Track payment status.
- 🌱 **Crop Price & MSP Information** – View crop prices and starting rates.
- 🤝 **Price Negotiation** – Farmers can bargain with administrators.
- 🧾 **Digital Procurement Receipt** – Access procurement details digitally.
- 🎙️ **Voice Connect** – Send and receive voice messages between farmers and administrators.
- 🌐 **Multi-Language Support** – English, Kannada, Hindi, Marathi, Telugu, and Tamil.
- 🔐 **Admin Dashboard** – Manage farmers, procurement activities, and communication.
